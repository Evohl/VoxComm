# VoxComm controller actions (Star Citizen)
#
# Format:
#   Action name => keyword groups => ButtonN [hold] => {DE} reply | {EN} reply
#
# Keyword groups:
#   +            AND between groups: every group needs one match in the request
#   , or |       OR inside a group: any alternative matches
#   {set}        reusable keyword set (defined below, expanded inside groups)
#   ButtonN hold press and hold for about 1 second (default: tap)
#
# Lines starting with # are ignored. Sets are defined with {name}: keyword, keyword
# Matching ignores case, umlauts (ä=ae, ö=oe, ü=ue), and simple inflections.
#
# Preconditions: [field value] line applies to all following action rows until the next [...] line.
#   [pilot seat yes]   only when the Star Citizen log reports the pilot seat (also: [pilot seat no])
#   [in ship yes]      only when the Star Citizen log reports being in a ship (also: [in ship no])
#   []                 clears the precondition
# Unknown state (no log data yet) blocks actions with a precondition until the game log confirms the required state.
# Custom replies per action and language are set in Settings; the {DE}/{EN} texts here are the defaults.

{call}: call, hail, rufen, kontaktieren, anrufen
{deploy}: deploy, ausfahren, ausklappen, herunterfahren
{retract}: retract, einfahren, einklappen, hochfahren
{aktivieren}: an, on, aktivieren, einschalten, enable, activate
{deaktivieren}: aus, off, deaktivieren, ausschalten, disable, deactivate
{sperren}: sperren, verriegeln, lock
{entsperren}: entsperren, entriegeln, unlock
